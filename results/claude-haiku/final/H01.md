# AFS technical assessment

Our existing NIR pilot follows API concentration in one powder formulation at
the tablet press feed frame. We are introducing a different API and excipient
blend and would like to reuse the calibration. A colleague suggests adding
Raman so that the old calibration will remain valid. What should our first
technical assessment and experiment be?

Evidence release: afs-official-v2

Source citations: present_with_gaps (not scientific verification)

Decision status: Further clarification needed

## Answer

The inspected sources name NIR and Raman as the most widely implemented techniques for blend potency in the feed frame of a rotary tablet press [1]. A multispectral NIR-Raman fiber probe with an industrial-grade shaft that fits a tablet press feed frame is described [2]. One source states that combining Raman and NIR can predict API potency with higher accuracy and robustness than single-method models [3], but the cited passage gives no models, samples or measured errors.

NIR is described as the most common online analysis method performed with fiber optic probes [4]. NIR penetration can reach several millimetres into dense solids, which suits online fiber-probe use [5].

None of the inspected passages addresses calibration transfer, or shows that adding Raman keeps an existing NIR calibration valid for a different API and excipient blend. The colleague's premise is therefore untested and should not be assumed.

Conditional interpretation: a model built on one formulation may not hold for a different API and excipient blend, and a combined NIR-Raman model uses different inputs, so the old NIR-only calibration cannot be assumed to remain valid after Raman is added. NIR spectra consist mainly of overtones and combination bands of many molecular groups [4], so changing the API and excipients may shift spectral contributions; this is a concern to test, not a demonstrated failure.

Proposed first study: obtain representative new-blend samples across the agreed range and realistic feed-frame variation, and measure them with the existing NIR setup and, if access allows, a combined NIR-Raman probe at matched times, each paired with independent reference results. Apply the unchanged old calibration to establish current transfer, then fit any recalibration on a training subset and validate both NIR-only and NIR-plus-Raman models on independent held-out batches. A diffuse reflection NIR probe is listed for powder samples with a 0.5-1 mm optical path [6].

Before a selection is made, please provide the identities of the new API and excipients and the target variable and range, the reference method with its uncertainty, the acceptable error limit and result timing, realistic feed-frame variation, access and cleaning constraints, and the budget for a higher-cost combined probe.

## Approaches worth testing

### Existing NIR diffuse reflection probe (retained baseline)

NIR spectra span 780-2500 nm and contain mainly overtones and combination bands of molecular groups. [4]

NIR is described as the most common online method using fiber optic probes. [4]

A diffuse reflection NIR probe is listed for scattering media and powder with a 0.5-1 mm optical path and average cost; these ratings are qualitative, not measured performance. [6]

**Measurement / probe concept:** Diffuse reflection NIR probe at the feed frame, as in the existing pilot; the pilot's hardware is not described in the inspected evidence. [4, 5, 6]

**Spectral range:** Nominal NIR 780-2500 nm from the method description; not confirmed system coverage. [4, 5, 6]

**Limitations:**

- No inspected passage shows that the existing calibration remains valid for a different API and excipient blend.

**Assumptions to confirm:**

- The existing probe geometry and pilot setup at the feed frame are unchanged.
- The old calibration transfers only if the new blend's spectral variation is covered by the existing calibration or by recalibration data.

### Combined NIR reflection and Raman multispectral fiber probe (optional hypothesis)

The source reports that combining Raman and NIR can predict API potency with higher accuracy and robustness than single-method models; the cited passage gives no models, samples or measured errors. [3]

A multispectral NIR-Raman fiber probe is described as combining NIR reflection and Raman in a compact industrial-grade shaft that fits a tablet press feed frame; no performance data are given. [2]

Raman is an excitation-laser vibrational method reported as a Raman shift in cm-1; its signal is weak and can be complicated by laser scattering and fluorescence, which may require special probes. [8, 9]

The Raman probe row is rated high cost, with a 2-5 mm optical path and liquid, powder and solid sample types; ratings are qualitative. [7]

**Measurement / probe concept:** Combined NIR reflection and Raman probe at the feed frame, as in the source's example design; installation only if process compatibility, access and cleaning are confirmed. [1, 3, 2, 7, 4, 8, 9]

**Spectral range:** NIR nominal 780-2500 nm from the method description; Raman shift range and excitation wavelength are not stated in the inspected evidence. [1, 3, 2, 7, 4, 8, 9]

**Limitations:**

- Higher cost and complexity than NIR alone; the added value for this blend is unknown.
- Weak Raman signal, laser scatter and fluorescence may limit usefulness for some formulations.

**Assumptions to confirm:**

- The new API and excipients give a usable Raman signal without problematic fluorescence, or the probe design can manage it.
- A combined model is fitted on new-blend data for both channels and is not assumed to inherit the old NIR calibration.

- The inspected sources give no prediction accuracy, sample set or feed-frame performance data for either method, so the requested certainty about transferability cannot be supported.
- Ratings in the method table are qualitative and are not measured performance.
- Raman alone is not a candidate here and is deferred until the NIR and combined comparison shows whether added value is needed.

## First feasibility study

Decide whether the existing NIR calibration remains adequate for the new API and excipient blend without recalibration, whether NIR recalibration meets the agreed limits, and whether adding Raman gives enough measurable benefit to justify its cost and complexity.

1. Gather prerequisites first: reference method and uncertainty, agreed error and bias limits, target range and the new blend composition.
2. Prepare or obtain representative new-blend samples across the agreed range and realistic feed-frame variation, with paired independent reference results at matching times.
3. Measure all samples with the existing NIR setup and, where access allows, with a combined NIR-Raman probe on the same material and timing.
4. Apply the unchanged old NIR calibration to the new blend to establish current transfer performance.
5. Fit any NIR-only recalibration and any NIR-plus-Raman model on a training subset of batches, with preprocessing fitted only on that subset.
6. Validate both models on independent held-out batches against the same reference values and compare them with the unchanged calibration.
7. Check Raman spectra for fluorescence and laser-scatter problems before interpreting any added value.

## Criteria to agree and check

- Whether the unchanged old calibration meets the customer's agreed error and bias limits on the new blend; if it does, it is the simplest adequate option.
- Whether NIR-only recalibration meets the limits on held-out batches; if it does, the simpler option is preferred.
- Whether the combined NIR-Raman model improves error, bias or robustness on held-out batches by a margin the customer judges practically useful given its higher cost and complexity; statistical significance alone is not sufficient.
- Whether Raman spectra are usable for the new blend; if fluorescence or weak signal prevents useful results, the combined option is not adequate.
- Inconclusive results or no practically useful gain are valid outcomes and would not justify adding Raman.
